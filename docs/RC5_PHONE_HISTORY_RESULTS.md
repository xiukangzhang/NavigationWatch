# 1.0 (6) iPhone顺序、导航白底与最近目的地

2026-10-08。用户追加要求：搜索在上、导入在下，删除首页底部来源文字；导航信息居中、白底铺满；新增默认折叠、可删除的最近目的地。

## 实现

- 首页搜索卡在上、导入卡在下。首页底部“地图与导航数据由高德提供”删除，设置页原有高德来源和隐私/服务条款保留。
- 导航页面转向、距离、道路、事件、剩余信息与Stop居中；白色背景延伸至屏幕安全区，导航期间明确使用浅色文字环境以避免深色模式白底白字。内容本身仍遵守安全区、允许滚动，停止后恢复首页主题。
- 最近目的地由用户明确确认：默认折叠，最多20个，仅在路线规划成功后记录目的地；可重新选用、逐项删除与清空，重新打开App仍能读取。按ID或近似同名同坐标去重；无效/损坏数据不会阻断首页。
- 本机UserDefaults保存名称、可选地址、目的地坐标和ID，不保存起点、导航会话、行驶轨迹、时间或完整路线。删除与清空立即写回本机存储；不引入账号、云同步或服务器。Privacy Manifest已有UserDefaults CA92.1，未新增required-reason类别。
- 历史重新选用沿用隐私同意、定位权限、AMap算路与用户确认开始导航，不自动开启GPS导航。Watch、Widget、Provider/freshness和同步不改。
